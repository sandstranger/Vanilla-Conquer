# C&C-style Siege Tank native regression

Run `siegetank_engine.cpp` through the existing private mission-start probe harness. It requires the legacy mission fixture and a copied `current-user.sav` in the private directory. Never replace live save files with probe fixtures. After any probe, restore missionstarts.cpp (the harness does this in finally), rebuild the normal executable, and run CTest before installation.

Checks cover the separate GDI/Nod production entry, factory output, loaded native sprites/cameo, 150 HP, one point of flat armor, sight 10, approximately 50 game seconds of production, tank 30 damage/range 7/reload 23 ticks, siege 70 damage/range 12/reload 47 ticks, a three-second conversion in either direction, no movement or firing during conversion, no movement after deployment, minimum range 2, reacquiring a valid distant target despite an enemy inside minimum range, no airborne targets, real travelling shell damage, three splash rings, friendly splash, both forms and pending conversion round-tripping through Save_Game/Load_Game, and legacy mission/current-user save compatibility.

The first compatibility run rejected the old fixture: changing UNIT_COUNT also enlarged two embedded UnitTrackerClass arrays in HouseClass. Preserve the original 22-entry statistics and quantity arrays. Guard all writes of new unit IDs into those arrays. Existing unit IDs, raw object sizes, and save-version calculation remain compatible. The new optional footer follows the existing formation footer and stores only pending conversion deadlines. Its loader runs before pointer decoding and must not dereference encoded Class/House pointers.

C&C adaptation: use original medium-tank art while mobile and mammoth art while deployed, with a separately labeled SIEGE TANK cameo. Both factions can produce it with the existing all-tech campaign feature. Cost is 1500 credits because this game has no gas/supply resource system. There is no separate research step. Preserve the game's established global campaign auto-repair. New units are omitted from the legacy multiplayer per-type telemetry arrays to preserve the save ABI; total unit counts and live heap scans still count them.

Reference values: BWAPI's original-game unit/weapon data, https://github.com/bwapi/bwapi/tree/main/bwapi/BWAPILIB/Source (UnitType.cpp and WeaponType.cpp). Native 15-tick simulation approximates Brood War's 37/75-frame weapon cooldowns at 24 frames per game second as 23/47 ticks. Splash radii 10/25/40 original pixels become 10/32, 25/32, 40/32 C&C cells; damage is full/half/quarter before unit-size scaling. Infantry takes half explosive damage, small native vehicles take three quarters, and other vehicles/buildings take full damage. C&C has no original StarCraft upgrades, gas, supply, or transport rules.
