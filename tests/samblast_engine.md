# Player campaign SAM: 20 cells, logarithmic simultaneous volley, five ricochets

`samblast_engine.cpp` remains the compatibility entry point and includes `samvolley_engine.cpp`; the common native scene helpers live in `samtest_support.h`. Run either entry point using the isolated `evidence/sam-density-five-20261106/probe_native.py` runner. It temporarily substitutes missionstarts.cpp, executes the real engine and mission assets against private copies, and restores the source in finally. Rebuild the normal executable and run CTest after all probes. Never overwrite live user saves.

Only the local human player's campaign SAM receives the new rules. Weapon range is 20 cells. At each actual Fire_At, eligible hostile mobile actors in range are counted: fewer than 10 -> one root missile, 10 -> two, 20 -> three, 40 -> four, 80 -> five, then 160/320/640 -> six/seven/eight. Count excludes buildings, allies, neutral actors, dead/limbo actors, cloaked actors and undiscovered ground actors. Existing airborne discovery rules are preserved. Extra roots select distinct nearby actors other than the main SAM target. The population is sampled once per firing; chain impacts never trigger another population volley. The previous damage, half-speed projectile flight, splash-free impacts, ten-cell bounce search, fivefold HP, armor, paid automatic repair and attack cadence remain in place.

Each root and extra projectile can produce up to five travelling ricochets, whether an impact hits or misses. With available nearby targets this is six impact attempts including the root. Each chain stops early when no valid enemy is within the existing ten-cell bounce radius. A missing/removed target still consumes an attempt and searches from the actual missile position. No changes to native raw object layouts are needed.

New chain files use CNCCHN04. The record retains 16 words (the historical eleven-entry storage capacity) to keep parsing simple. New records validate remaining + used = 5. Load versions 01/02 with the original 8-word records and version 03 with 16 words. Validate using the source version's budget (2 or 10), then retain the consumed attempts and set the remaining budget to max(0, 5-used). Older missiles that have already consumed at least five attempts get no further ricochets; their current flight may still impact once. Reload never grants fresh root missiles or a refreshed budget. Pointer-dependent fixup remains after Decode_All_Pointers.
