# Recursive enemy-unit fusion

Campaign AI checks once per game second. Five same-house, same-native-class, same-tier mobile actors within ten cells of an anchor become one actor of the next tier. Aircraft must also agree on airborne/landed state. This does not apply to player, neutral, allied, defeated, human or skirmish houses. Cargo, harvested tiberium, radio contacts, tethers and pending Siege Tank conversion defer fusion; mission-trigger donors are retained so scripted objectives are not silently discarded. The surviving anchor keeps its trigger, mission, target, destination, ammo and native class. Other actors are stunned and deleted through native cleanup without damage, deaths, crew, kill rewards or new production companions.

Each tier multiplies both sprite dimensions by 1.3, independently of the twofold projectile damage and maximum HP. Visual scale is computed as a rounded 8-bit fractional presentation value; combat multiplier remains 2^tier. Health percentage is averaged across the five inputs, so fusion does not heal a damaged army to full. Movement speed, range, reload and pathfinding footprint remain native. Sprite component offsets, health bars and cache-backed paletted pixels scale together. Native fades, shadows, cloak rendering and smooth-motion layer recording remain active. A full tactical redraw while upgraded actors exist avoids trails outside the native dirty-cell bounds; enlarged actors use extended viewport culling. Native 16-bit health/projectile fields saturate at 32767, raster dimensions at 2048, and tiers at 5 rather than overflowing. Ordinary units are unchanged.

State is a TARGET-to-tier sidecar, not a new field in serialized objects. The optional `CNCFUS01` footer follows the Siege Tank footer. Its parser validates IDs/counts/tiers/duplicates without touching encoded Class/House pointers; live-object validation runs after Decode_All_Pointers. Old mission and current-user saves load with tier zero, and existing enemies can then fuse normally. Constructors, destructors and scenario resets clear stale sidecar IDs before heap reuse.

Run `enemyfusion_engine.cpp` through `/private/tmp/cnc-ion-hostile-probe.py` (private native mission-start runner). It uses copies of legacy fixture and user saves only; never overwrite live saves. The native checks cover four-versus-five, repeated evolution in infantry/vehicles/aircraft, type/house/tier/distance boundaries, allies and skirmish, damaged health averages, native Logic AI invocation, donor occupancy release, scripted actor preservation, real projectile strength, unchanged range, legacy/current-user save loading, two-tier save/reload, heap reuse, malformed footers, exact raster-pixel resampling at fractional sizes, palette cache restoration, ten-cell exact distance boundaries, first-through-fifth-tier stats and no sixth-tier fusion, old upgraded-save compatibility, count changes on fusion/death/limbo, actual counter redraw, and a captured actual native gameplay render showing 1x/1.3x/1.69x/2.197x/2.8561x/3.71293x units with the live enemy-count HUD. A private negative run disables AI and must fail the first evolution checks. The runner restores missionstarts.cpp in finally; always rebuild the normal game and run CTest before installation.

The top-left tactical HUD labels deployed enemy infantry, vehicles and aircraft as NORMAL and LEVEL 1/2/3/4/5, including zero counts. It includes off-screen/unseen field enemies and excludes buildings, allied/neutral/player actors, dead actors, unfinished products and cargo in limbo. Counts are recomputed from native live heaps, and redraw is invalidated when counts change, including when no upgraded actors remain. It uses the existing English game font. The save schema is unchanged. Legacy tiers 6–15 are accepted by the footer parser then normalized to tier 5 after pointer decoding, retaining health percentage against the old capped maximum. This normalization is idempotent. Valid existing tiers 1–5 preserve their combat stats and use the new visual size.

For the previous HUD revision, privately restoring 2x visuals and the five-cell radius must fail the scale and radius checks; independently omitting Draw_Counts must fail the actual counter-redraw check. Run those controls separately because a failed third-tier creation can otherwise skip the later HUD checks.

The current limit regression builds five actual level-five actors (15,625 base actors created and fused sequentially within the native pool) and proves they remain separate after repeated AI passes. The visual fixture contains the base actor plus all five upgrade stages. Private negative control permits a sixth-tier merge and restores 1.5x visual scaling, which must fail the cap and scale checks. Old level-six half-health and level-fifteen full-health fixtures normalize to level five with the same health percentage.
